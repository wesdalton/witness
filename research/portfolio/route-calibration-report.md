# Route capability pilot: all correct, with tool-interface recovery

All eight no-peer route audits completed correctly. Every final program also
returned the correct value on all 30 frozen fresh conditions: eight greedy traps,
eight ordinary graphs, eight renamed graphs with changed endpoints, and six
boundaries. This is eight model episodes and eight programs, not 240 independent
model replications. No peer treatment has yet been evaluated on this task.

Agents executed 3, 2, 2, 4, 2, 5, 3, and 3 queries respectively. Two episodes first
sent multiple SQL statements in one tool call; SQLite rejected those calls and
the agents recovered by separating them within their unchanged query allowance.
These were ordinary SQL interface errors, not Daybreak rejections. Every actual
optimization query used correct all-pairs reasoning; additional queries inspected
graph data or returned witness paths. No reference counterexample was found.

Three false publishers returned -1 even though feasible pairs existed; the fourth
reported a feasible but suboptimal cost (65 versus optimum 49). The auditors
identified these differences with valid path pairs and complete optimization.
The full supplied query includes most of a correct enumerator, so repairing its
final greedy selection may make the task easier. Do not claim this is intrinsically
hard merely because the task has interacting combinatorial constraints.

Twenty-nine requests cost $0.008682365 with $0.114933000 retained reservations.
Phase totals: 435 requests, $0.407355740 charges, $5.810092000 retained reservations.
All outputs, source snapshots, and query replays are retained.

The repeated ceiling raises a measurement question: requiring a reusable verifier
may itself elicit checking. Prepare a small matched output-requirement ablation,
with a common substantive contract, fixed tool access, and neutral/endorsement
conditions. Claim judgment is the common endpoint; absence of an unrequested
program must never be scored as failed verification. This is a new mechanism
screen, not a larger replication of the same mandatory-program task.
