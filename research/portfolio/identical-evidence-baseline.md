# What the identical initial evidence establishes

The same_program route construction presents the same system prompt, submit/query
tools, publisher SQL, reported total, execution receipt, contract, schema, query
parameters, and peer messages for the true and false member of each seed/condition
pair. The hidden source database differs. Reference totals, truth, seeds, source
hashes, and qualification metadata are saved for evaluation but not sent to the
model. The Responses adapter clears native history at each new episode. Initial
execution timing is omitted. Free live checks establish initial-view equality;
the analysis repeats it on the actual saved model views.

For a policy that obtains no new database evidence, its distribution of output
probabilities must be the same across those indistinguishable inputs, assuming
no outside state correlated with the label. The sample order is shuffled and all
episodes are fresh. On the balanced pair, for any common probability p, average
Brier loss is [p² + (1-p)²]/2 = (p-0.5)² + 0.25, minimized at p=0.5. Randomization
does not improve the expected minimum. A forced binary decision has expected
accuracy 0.5. Finite realized stochastic outputs can depart from these expectations;
do not treat the bound as a deterministic per-sample score test.

This is an information baseline, not a novelty claim or new primary endpoint.
It explains why code recognition or endorsement alone cannot reliably solve the
new finite claim. It does not mean every query provides useful evidence: SELECT 1,
a schema lookup, or a repeat of the flawed publisher query can be insufficient.
Inspect actual observations, correct optimization, and the final program separately.
Conditioning on whether an agent queried is post-treatment selection and does not
identify a causal checking effect. The randomized interface/peer contrasts remain
the basis for causal interpretation.

The secondary cell and peer summaries implement endpoints already named in the
frozen protocol. They were added to the analysis script while the fixed batch ran;
the original frozen analyzer remains in the batch source snapshot. No prompt,
sample, stopping rule, scoring formula, or primary endpoint was changed.
